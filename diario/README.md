# Diário

Dois registros que alimentam a repetição espaçada:

- [`bugs.md`](bugs.md): todo bug seu ou da IA que você encontrou. Cada entrada vira um cartão.
- [`decisoes.md`](decisoes.md): decisões técnicas curtas (mini-ADRs). Releia todo mês.

Para decisões maiores, use `modelos/modelo-adr.md`. Para incidentes, `modelos/modelo-post-mortem.md`.
