# Cartões (Anki)

## Como importar

1. Abra o Anki e use **Arquivo > Importar**.
2. Escolha `fase-0.csv`. As três colunas são: frente, verso e etiquetas (o arquivo já traz as diretivas para o Anki reconhecer isso).
3. Confirme o tipo de nota "Básico" e o baralho de destino.

## Regras

- **Vira cartão:** trade-offs, modos de falha, previsão de comportamento de código, ordens de grandeza e os seus próprios erros.
- **Não vira cartão:** sintaxe, comandos decorados e parâmetros de SDK.
- No máximo 5 cartões novos por dia. Reescreva cada cartão com as suas palavras se a resposta não fizer sentido para você.
- Todo bug do `diario/bugs.md` deve gerar um cartão.

## Novos cartões

Crie um arquivo por fase (`fase-a.csv`, `fase-b.csv`, ...) com o mesmo formato, para manter o histórico versionado.
